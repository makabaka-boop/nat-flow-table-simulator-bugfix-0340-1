

## 已发布本地端点的回环会话
Publish / Unpublish 以预期发布修订管理固定公网端口、本地端点和允许发起会话的精确本地端点名单。
固定发布与动态映射共用同一端口池；发布失败不改变修订或端口归属。普通远端流量仍走 Translate。
本地客户端使用 TranslateHairpin 向已发布公网端点发包，接收端看到客户端的转换后公网来源，
回复该地址时应回到原客户端，回复来源仍为对端的固定发布地址。整次转换的许可、端口分配、
正反向身份与状态记录必须一致；被拒绝的包不建立或刷新会话。
替换或撤销发布立即终结旧发布身份的回环会话，旧接收端的回复不得进入新发布；
新会话重新按当前名单裁决。会话最后一次合法使用后 30 秒到期，恰到期视为失效，
端口回收不得遗留可命中新端口拥有者的旧回复身份。发布列表与活动映射数应能解释每次转换。
